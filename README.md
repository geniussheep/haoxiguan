# 杨妙绮小公主的好习惯魔法存折 👑✨

> 专为培养孩子良好生活与学习习惯设计的全栈响应式 Web 魔法记分与心愿商城系统。

---

## 🌟 项目亮点

1. **公主魔法主题设计**：
   - 适配移动端与桌面端自适应布局，支持 8 位迪士尼公主个性化切换与专属鼓励语录。
   - 包含音效反馈系统（Web Audio API + 烟花祝贺音频）、粒子流星动效。
2. **打卡与记分规则**：
   - 预设生活好习惯、家务劳动、火眼晶晶识字奖励、周全勤任务以及惩戒规则。
   - 实时积分折算与可视化目标进度条（冲刺迪士尼 500 分终极梦想）。
3. **心愿兑换商城**：
   - 支持兑换现金零用钱（10:1 汇率存入透明存钱罐）与实体心愿奖励。
   - 内置防重复兑换撤销日志与明细追溯。
4. **轻量高性能服务端架构**：
   - **后端驱动**：Python 原生多线程 HTTP 服务 + SQLite3（启用 WAL 预写日志与连接池并发加锁机制）。
   - **双向兼容**：支持 SQLite 关系型存储与传统 `data.json` 自动同步。
   - **静默多端同步与防闪屏**：前端通过状态指纹比对机制（`computeStateFingerprint`）定时拉取云端，有实际数据更新才更新视图，杜绝页面闪屏。

## 📁 目录结构

```text
├── index.html                  # 前端单页面应用主文件 (UI / 交互 / 状态管理 / 动效)
├── server.py                   # 后端 HTTP 服务器 (提供静态托管与 /api/data 接口)
├── db.py                       # SQLite 数据库访问层 (WAL模式 / 事务 / JSON同步)
├── habit.db                    # SQLite 主数据库文件
├── data.json                   # 兼容备份 JSON 数据文件
├── princess_rules_pdf.html     # 打印版守则与心愿兑换图表
├── 同步云端数据.command          # macOS 双击一键同步云端数据快捷指令
├── scripts/
│   └── sync_from_server.sh     # 每日云端数据自动拉取与备份脚本
├── avatars/                    # 8位迪士尼公主头像资源库
├── favicon.ico                 # 网站图标
├── fireworks_bgm.mp3           # 达成500分烟花盛典背景音乐
└── 快乐无边.mp3                # 奖励音效资源
```

## 🚀 本地运行

无需安装重量级框架，Python 3 原生直接启动：

```bash
# 进入项目目录
cd 好习惯打卡网站

# 启动本地服务 (默认端口 8080)
python3 server.py --port 8080
```

打开浏览器访问：`http://localhost:8080/`

---

## 🔄 云端同步机制

- **云端生产部署**：部署于腾讯云 CVM 实例，通过 systemd (`xiguan.service`) 守护进程长期托管。
- **本地定时拉取**：本地配置了每日定时同步任务（基于 macOS `launchd` 与 `scripts/sync_from_server.sh`），自动将云端打卡记录同步覆盖至本地并保留一次历史备份。
